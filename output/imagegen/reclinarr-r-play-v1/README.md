# Reclinarr R/play logo concepts

Generated with the built-in image generation tool. Preview raster assets; not applied to the app.

## App icon prompt
Create a square app icon with a clearly recognizable bold capital R: one upright stem, rounded enclosed upper bowl, diagonal leg down-right, and a right-facing play triangle as the negative-space counter inside the upper bowl. Amber R on dark charcoal, soft geometric rounded styling, generous padding, crisp solid fills. No chair, wordmark, texture, glow, 3D, or other symbols.

## Website logo prompt
Use the generated app icon as the identity reference. Create a matching horizontal website lockup on midnight charcoal (#11141b). Reproduce the R/play symbol on the left without the app tile. On the right use the exact lowercase word reclinarr in rounded geometric semibold sans serif: off-white reclina and amber rr. Symbol height 1.4 times letter height, vertically centered, generous margins. Clean flat fills, smooth edges, no tagline or mockup.
